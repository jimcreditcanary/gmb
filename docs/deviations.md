Scope: this file lists **every change a visitor, editor, search engine or regulator could notice** compared with https://www.gmbcreditunion.com as archived on 2026-10-06 (`source/html`). Rule for maintainers: if you change copy, colour, layout, behaviour, a URL, or anything regulatory, add a row here in the same PR.
