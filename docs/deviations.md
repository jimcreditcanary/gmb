Scope: this file lists **every change a visitor, editor, search engine or regulator could notice** compared with https://www.gmbcreditunion.com as archived on 2026-10-06 (`source/html`). Pure under-the-hood engineering (framework, hosting, caching, image formats, code splitting) is *not* listed. Each entry says what changed, why, who approved it, and how to revert.

Rule for maintainers: if you change copy, colour, layout, behaviour, a URL, or anything regulatory, add a row here in the same PR.
